# 运转计划助手（交通迷绕路运转规划工具）

> 面向交通迷的绕路运转行程规划工具——不做自动寻路，按「起点站 → 线路 → 方向 → 到达站」链条式手动规划，自动计算时长、验证换乘并导出 A4 彩色运转图纸。

普通地图软件追求"最短/最快路径"，而交通迷运转的核心是**绕路**——为了体验某条线路、某趟车型、某个冷门站点而故意绕行。本软件**不做自动寻路**，采用「链条式手动规划 + 智能提示」：把想坐的线路一段段串起来，软件负责查数据、算时长、验换乘、出图纸。

- **技术栈**：Python 3.10+ · PySide6（Qt 界面） · reportlab（PDF）
- **平台**：Windows（macOS/Linux 需自行配置中文字体）

## 功能

- **统一建模几类交通**：地铁 / 市域铁路 / 有轨电车 / 公交 / 国家铁路 / 磁浮 / 轮渡，并支持**自定义交通类型**（在添加行程窗口点「自定义…」，保存后长期可用）
- **线路标志色（支持双色）**：主色 + 副色（如国铁黑白双色、上海磁浮绿橙），界面色块、PDF 色带与时间轴均按双色渲染
- **终点站方向**：不用"上行/下行"，直接标注方向终点站（如"富锦路方向"）
- **发车班次**：只写班次（"高峰4分钟一班 / 平峰8分钟一班"），不写等车时间；间隔填 0 表示**不定班**（无固定间隔，如部分公交/轮渡）
- **国铁时刻表**：可录入车次 / 发时 / 到时（如 G123 07:00→09:07），PDF 中以时刻表表格呈现
- **按时刻表乘坐**：勾选后启用时刻表编辑，并自动按发时/到时计算运行时长，无需手输；下方附铁路12306 查询链接；未勾选即公交化运营（按固定间隔发车）
- **票价**：每段行程可手动填写票价，右侧统计与 PDF 汇总自动求和
- **付费区模式**：勾选「付费区模式」后，不出闸的连续行程视为一段付费区，票价按**进闸站→出闸站**一次计费（即使绕路也只收一次费），并在统计与 PDF 中展示付费区明细
- **转乘（跨付费区）**：段间换乘条上可勾选「转乘」（跨付费区、需出闸/换系统，如 地铁↔国铁）；地铁线路库中的转乘站（如 上海南站↔上海南）会自动勾选。勾选后本段开始一个新的付费区
- **同站异名**：线路库可声明同站异名（如 广州西塱↔广佛线西朗），换乘按同站（步行 0）处理
- **同城组合模式**：内置 上海-苏州 / 广州-佛山 / 珠江三角洲 同城模式，直接在代码中合并两座城市的线路库（不额外生成大文件），跨城同站（如 花桥）自动识别
- **设置界面**：可保存最常出行城市 / 地铁站 / 公交站（下次规划第一段自动预填），自动保存开关与保存位置，在线地图 API 密钥与**获取教程**，以及版本信息；设置随 QSettings 持久化，关闭软件不丢失
- **手动输入为默认**：主界面一个「＋ 添加行程」大按钮，弹窗中仅「线路名称 + 到发站」必填，其余选填；手动输入线路时可用**单选按钮**选择交通类型（地铁/公交/市域铁路/轮渡…），并可**自定义新的交通类型**
- **线路名智能推荐**：输入线路名时按城市线路库弹出下拉推荐，选中后自动套用该线路的方向、颜色、班次、站点等全部信息
- **在线地图数据源（可选）**：在设置中配置高德 / 百度 / 腾讯 API Key 后，线路名本地未命中时可从地图 API 获取线路经停站、首末班车等**线路信息（不含实时状态）**；未配置则完全使用本地数据 / 手动输入
- **段间换乘步行**：每两段行程之间可单独配置站外步行分钟（同站换乘记 0）——不是所有换乘都是同站换乘
- **换乘提示**：在当前站自动列出可换乘的线路及方向
- **分段时间与全程统计**：站间运行时长累加 + 逐段换乘/站外步行，右侧实时显示总时长 / 运行 / 步行 / 换乘次数 / 线路数 / 总站数
- **彩色时间轴**：按运行时长成比例绘制的分段色带
- **PDF 导出**：导出前可选**导出目录**与**中文字体**（常用预设或自定义浏览）；A4 中文排版，含彩色时间轴、每段经停站完整列表、发车班次、换乘节点；**线路名称旁标注交通类型**（地铁/公交/市域铁/国铁/轮渡…），可直接持图运转
- **数据编辑器**：可视化维护城市、线路、站点、站间时长、班次、标志色；站点/区间以**线路图风格**展示（`o-o-o-o`，圆圈=车站、线段=区间+时长，单击选中、双击编辑、`+` 加站），主线与支线合并显示并可点击分离点新建支线
- **方案保存/载入**：行程方案以 JSON 保存，可反复调整绕路方案
- **可扩展**：`transit_planner/providers/` 预留统一数据接口，后续可接入高德 / 百度 / GTFS 等在线数据

*请注意：内置的广州、深圳、佛山、东莞的城市线路不全，也不十分准确，要生成运转计划，建议优先手动录入。后续将进行优化。*

## 安装与运行

需要 **Python 3.10+**（已在 3.14 上测试）。

```bash
# 1. 安装依赖（国内网络可加 -i https://mirrors.aliyun.com/pypi/simple/）
pip install -r requirements.txt

# 2. 启动
python app.py
```

> 导出 PDF 时可在「导出设置」中选择中文字体（默认微软雅黑，也可自定义浏览其他字体文件）；
> 若需直接修改默认字体，可编辑 `transit_planner/pdf/exporter.py` 顶部的 `DEFAULT_FONT_REGISTRY`。

## 使用流程

1. 启动后选择城市（内置：上海 / 北京 / 苏州 / 广州 / 深圳 / 佛山 / 东莞 / 重庆，以及 上海-苏州 / 广州-佛山 / 珠江三角洲 同城模式），左侧为线路库（点击查看详情，双击可在添加窗口预填该线路）；
   也可先在「**设置**」中保存最常出行城市/地铁站，下次新建方案时自动选择该城市并预填起点站
2. 点击醒目的「**＋ 添加行程**」大按钮，在弹出的窗口中输入线路信息
   - **仅「线路名称」与「起点站 / 到达站」为必填**，其余（方向、运行时长、经停站、发车班次、备注、线路色、时刻表、票价）均为选填
   - 默认按**手动输入**处理；输入线路名称时弹出下拉推荐，选中推荐后自动套用该线路的方向、颜色、班次、站点等全部信息
   - 本地未命中时，若已配置在线地图 API，会自动从地图查询线路（经停站 / 首末班等线路信息）
   - 勾选「**按时刻表乘坐列车**」后可编辑时刻表，运行时长自动按发时/到时计算，并可点「铁路12306」跳转查询本段车次
   - 若推荐线路的起终点都在该线上，则按数据库计算运行时长与经停站；否则退化为手动段（沿用该线路名称 / 颜色）
3. 添加后每段行程以**卡片**展示详细内容；添加两段及以上时，两段之间会出现「**换乘**」配置条，可逐段指定换乘步行分钟（同站换乘记 0），并可勾选「**转乘**」标记跨付费区换乘（需出闸/换系统，如 地铁↔国铁）；线路库中的转乘站会自动勾选
   - 适用于：跨城国家铁路（如京沪高铁 G123：上海虹桥→南京南）、数据库未收录的线路、国铁各车次运转
   - 「城市/范围」输入框可编辑：既可下拉选择内置城市，也可直接输入自定义范围（如"上海—北京"），此时纯手动规划
   - 内置数据已含双色示例：上海磁浮线（红+白）、金山铁路 / 京张高铁 / 京沪高铁（国铁黑白）
4. 右侧实时显示**当前位置的换乘提示**与**全程统计**，并有按运行时长成比例的彩色时间轴
5. 每张卡片上的上移 / 下移 / 编辑 / 删除可随时调整行程顺序与内容
6. 点「导出 PDF」先弹出**导出设置窗口**：可选**导出目录**与**中文字体**，确定后生成可直接对照运转的彩色文档
7. 在「**设置**」中打开**自动保存**并选择保存位置后，行程变更会实时写入 JSON，退出软件前自动保存，下次启动自动载入最近方案

## 数据说明

- 数据存于 `transit_planner/data/<城市>.json`，结构为人类可读 JSON，也可手工修改
- 内置为**主干线路种子数据**，站间时长多为估算近似值，**请以运营方实时信息为准**；可用「数据编辑」补齐与精修
- 换乘步行时间为默认估算，PDF 中会提示现场调整

### 城市库 JSON 结构

```jsonc
{
  "city": "上海",
  "lines": [
    {
      "id": "sh_m1",
      "name": "上海地铁1号线",
      "short_name": "1号线",
      "type": "metro",            // metro/suburban/tram/monorail/cloudrail/bus/national_rail/maglev/ferry，或自定义类型名
      "color": "#E60012",         // 线路标志色（主色）
      "color2": "#FFFFFF",        // 副色（双色标志色，如国铁黑白、磁浮；可留空）
      "operator": "",
      "stations": ["莘庄", "外环路", "…", "富锦路"],
      "travel_minutes": [3, 4, "…"],   // 长度 = 站点数-1（环线再多 1 个首尾闭合段）
      "headway_rush": 4,          // 高峰发车间隔(分)
      "headway_normal": 8,        // 平峰发车间隔(分)
      "first_train": "05:30",
      "last_train": "22:30",
      "ring": false,              // 环线
      "directions": [             // 留空则自动按两端终点站生成
        { "label": "富锦路方向", "terminal": "富锦路" },
        { "label": "莘庄方向", "terminal": "莘庄" }
      ]
    }
  ],
  "external_walks": { "站A|站B": 10 },   // 可选：跨站换乘步行分钟
  "transfers": [ [ "上海南站", "上海南" ] ],  // 可选：转乘站组（同地点不同名、不同付费系统，需出闸→标记"转乘"）
  "aliases":   [ [ "西塱", "西朗" ] ]         // 可选：同站异名组（同一车站同一付费系统，按同站换乘处理）
}
```

### 同城组合模式

在「城市/范围」下拉中可直接选择 **上海-苏州 / 广州-佛山 / 珠江三角洲**：
- 不需要额外的 JSON 文件，程序在代码中把参与城市的线路库合并为一座虚拟城市；
- 跨城同站（如 上海11号线支线↔苏州11号线 的「花桥」）自动识别为同站换乘；
- 两城各自的 `transfers` / `aliases` 会一并合并（如 广州「西塱」↔ 广佛线「西朗」为同站异名）；
- 同城组合为只读虚拟城市，「数据编辑」中不会出现，避免误写入。

### 行程方案 JSON 结构

```jsonc
{
  "name": "我的运转方案",
  "date": "2026-08-01",
  "city": "上海",
  "transfer_walk_default": 5,
  "paid_zone_mode": false,     // 付费区模式：按进闸站→出闸站计费，跨付费区转车标记「转乘」
  "steps": [
    {
      "line_id": "sh_m9",
      "direction_label": "曹路方向",
      "from_station": "徐家汇",
      "to_station": "肇嘉浜路",
      "walk_minutes": null,        // null=用默认；同站换乘自动为 0
      "manual": false,
      "type": "metro",            // 交通类型（手动段可自定义，如 轮渡）
      "line_name": "",
      "run_minutes": null,
      "stops_text": "",
      "color": "",
      "color2": "",
  "note": "",
  "headway_text": "",          // 手动段：发车班次文字（可选）
  "timetable": [],             // 手动段：时刻表 [[车次, 发时, 到时], ...]
  "use_timetable": false,      // 按时刻表乘坐列车（勾选后启用时刻表）
  "price": null,               // 票价(元)，手动输入
  "transfer": null             // 跨付费区转乘：null=自动（按线路库转乘站组判定）；true/false=强制指定
}
  ]
}
```

## 重新生成种子数据

`python -m transit_planner.tools.gen_seed`（会覆盖 `data/*.json`，请先备份自定义数据）。

## 目录结构

```
app.py                      入口
requirements.txt            依赖清单
transit_planner/
  __init__.py               包版本号（__version__）
  core/models.py            数据模型（线路/方向/城市/行程）
  core/engine.py            规划引擎（终点站方向、时长、经停站、换乘提示、自动选向）
  core/settings.py          应用设置持久化（QSettings）
  core/railway.py           铁路12306 查询链接生成
  pdf/exporter.py           reportlab PDF 导出（标志色/时间轴/经停站/班次/票价/自定义字体）
  ui/main_window.py         主窗口（行程卡片 + 换乘步行 + 统计 + 导出 + 自动保存）
  ui/add_step_dialog.py     添加/编辑行程弹窗（手动输入默认 + 线路名推荐 + 在线地图查询）
  ui/steps_panel.py         行程卡片面板（段间换乘步行配置条）
  ui/pdf_config_dialog.py   导出设置（目录 + 字体）
  ui/settings_dialog.py     设置界面（常用城市/站点、自动保存、地图 API、版本信息）
  ui/data_editor.py         数据编辑器
  data/*.json               城市线路库
  tools/gen_seed.py         种子数据生成器
  providers/base.py         数据提供方接口（预留在线 API）
  providers/online.py       在线地图 API 数据源（高德 / 百度 / 腾讯）
```
